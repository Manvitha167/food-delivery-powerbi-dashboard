# Food Delivery Analytics Dashboard – Power BI

## Project Overview

This project analyzes food delivery order data using Microsoft Power BI. The dashboard is designed to explore order performance, sales, customer ordering patterns, restaurant performance, product categories, and food delivery platform comparisons.

The dataset contains 15,000 unique food delivery orders across five platforms and four Indian cities.

## Project Objectives

- Compare order and sales performance across delivery platforms.
- Identify high-performing locations, restaurants, and product categories.
- Analyze order values, discounts, delivery fees, and payment methods.
- Understand vegetarian and non-vegetarian order patterns.
- Support data-driven business decisions using interactive Power BI visuals.

## Tools and Technologies

- Microsoft Power BI Desktop
- Microsoft Excel
- Power Query for data preparation
- DAX for calculations and KPIs
- GitHub for project versioning and sharing

## Dataset Description

The Excel dataset contains five platform-specific worksheets:

- Swiggy – 3,200 orders
- Zomato – 3,400 orders
- Magicpin – 3,100 orders
- EatSure – 3,000 orders
- Toing – 2,300 orders

**Total: 15,000 unique orders**

The dataset includes order IDs, order dates, cities, restaurants, products, categories, food types, quantities, unit prices, discounts, delivery fees, order values, payment modes, customer IDs, gross sales, and net food sales.

**Data disclaimer:** This project uses self-generated dummy data for learning and demonstration purposes. It does not represent actual company transactions or confidential customer information.

## Business Insights

The following observations are based on the supplied dataset:

1. **Platform performance:** Zomato has the highest order count, with 3,400 orders, followed by Swiggy with 3,200 orders.
2. **Location performance:** Hyderabad has the highest order count among the four cities, with 5,759 orders.
3. **Category performance:** Fast Food has the highest order count, with 5,034 orders, and the highest total order value among the listed categories.
4. **Platform comparison:** The dashboard can be used to compare order values, discounts, and sales measures across all five platforms.
5. **Business opportunities:** Businesses can investigate popular categories, location-wise demand, and discount patterns to identify opportunities for improving sales and operational performance.

These insights describe the supplied dummy dataset and should not be treated as real-world market findings.

## Dashboard Features

The Power BI report is intended to support interactive analysis through KPI cards, charts, filters, and platform, location, restaurant, and category comparisons, depending on the visuals implemented in the report.

## How to Use the Project

1. Download the `.pbix` file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. If prompted, review the data source settings and reconnect the Excel dataset if necessary.
4. Refresh the data if required.
5. Explore the report using its available charts, slicers, and filters.

## Limitations

- The dataset is synthetic and intended for educational analysis.
- Actual restaurant operating costs, platform commissions, and other expense details are not established by the dataset.
- Therefore, actual restaurant profit and delivery platform profit cannot be confirmed from the available sales data alone.

## Conclusion

This project demonstrates how Power BI can transform structured food delivery data into an interactive analytics report. It provides a foundation for comparing platforms, examining customer orders, and identifying potential business opportunities.
